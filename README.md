# Simple Inventory Tracker

**Task 30 – Veda Technology | Data Analytics Track**

## About the Project

For this task, I created a Simple Inventory Tracker using Microsoft Excel. The main purpose was to monitor product stock, compare available quantities with reorder levels, and identify products that need restocking.

## What I Did

- Created an inventory table containing product details.
- Added Current Stock and Reorder Level columns.
- Used an IF formula to automatically identify low-stock products.
- Applied Conditional Formatting to highlight products that need reordering.
- Created a separate Low Stock Report.

## Formula Used

`=IF(D2<=E2,"REORDER","In Stock")`

This formula checks whether the available stock has reached or fallen below the reorder level.

## Results

- Total products tracked: 15
- Products requiring reorder: 7
- Products currently in stock: 8

## Tools Used

- Microsoft Excel
- IF Function
- Conditional Formatting
- Excel Tables

## What I Learned

This task helped me understand how Excel formulas can be used for basic inventory management. I also learned how to identify low-stock products and highlight important information using Conditional Formatting.
